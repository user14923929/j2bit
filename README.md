# j2bit

**Java subset compiler for BBC micro:bit**

`j2bit` transpiles a subset of Java into C++ (CODAL), which you can then compile with `arm-none-eabi-gcc` and flash to your micro:bit v1 or v2.

```
.java  →  j2bit  →  .cpp  →  ARM GCC + CODAL  →  .hex  →  micro:bit
```

> ⚠️ This is an early-stage project. The supported Java subset is intentionally small.

---

## Features

- Lexer + recursive descent parser for a Java subset
- C++/CODAL code generation with micro:bit API mappings
- Helpful error messages with line/column numbers
- Single binary, no runtime dependencies

## Supported Java subset

| Feature | Status |
|---|---|
| Classes with static methods | ✅ |
| `int`, `float`, `boolean`, `String` | ✅ |
| `if / else`, `while`, `for` | ✅ |
| Arithmetic & logical operators | ✅ |
| `display.show()`, `display.clear()` | ✅ |
| `basic.pause()` | ✅ |
| `buttonA.isPressed()`, `buttonB.isPressed()` | ✅ |
| `Math.abs()`, `Math.random()`, etc. | ✅ |
| Instance methods / OOP | 🔜 planned |
| Arrays | 🔜 planned |
| Generics / reflection | ❌ out of scope |

## Installation

### From source

```bash
git clone https://github.com/user14923929/j2bit
cd j2bit
cargo build --release
# binary: ./target/release/j2bit
```

### From releases

Download the latest binary from [Releases](https://github.com/user14923929/j2bit/releases).

## Usage

```bash
# Compile Hello.java → Hello.cpp
j2bit compile Hello.java

# Specify output file
j2bit compile Hello.java --output out/Hello.cpp

# Print generated C++ to stdout
j2bit compile Hello.java --print

# Verbose mode (shows tokens and AST info)
j2bit compile Hello.java --verbose

# Only check syntax, no output
j2bit check Hello.java
```

## Example

**`examples/Hello.java`**
```java
public class Hello {
    public static void main() {
        while (true) {
            display.show("Hello, micro:bit!");
            basic.pause(1000);
            display.clear();
            basic.pause(500);
        }
    }
}
```

**Generated `Hello.cpp`**
```cpp
// Generated by j2bit — do not edit
#include "MicroBit.h"

MicroBit uBit;

void Hello_main();

void Hello_main() {
    while (true) {
        uBit.display.scroll(ManagedString("Hello, micro:bit!"));
        fiber_sleep(1000);
        uBit.display.clear();
        fiber_sleep(500);
    }
}

int main() {
    uBit.init();
    Hello__main();
    release_fiber();
    return 0;
}
```

## Compiling the generated C++ for micro:bit

You need the [CODAL toolchain](https://lancaster-university.github.io/microbit-docs/):

```bash
# Install arm-none-eabi-gcc (Ubuntu/Debian)
sudo apt install gcc-arm-none-eabi

# Clone CODAL project template
git clone https://github.com/lancaster-university/microbit-v2-samples
cd microbit-v2-samples

# Replace source/main.cpp with the generated file
cp ../Hello.cpp source/main.cpp

# Build
python build.py

# Flash MICROBIT.hex to your device
cp MICROBIT.hex /media/$USER/MICROBIT/
```

## Java → CODAL API mapping

| Java (j2bit) | C++ (CODAL) |
|---|---|
| `display.show(x)` | `uBit.display.scroll(x)` |
| `display.print(x)` | `uBit.display.print(x)` |
| `display.clear()` | `uBit.display.clear()` |
| `basic.pause(ms)` | `fiber_sleep(ms)` |
| `buttonA.isPressed()` | `uBit.buttonA.isPressed()` |
| `buttonB.isPressed()` | `uBit.buttonB.isPressed()` |
| `Math.random(n)` | `uBit.random(n)` |
| `Math.sqrt(x)` | `sqrtf(x)` |
